Master Quadratic Equations

Learn the same core concept through three difficulty levels — from guided foundations to real-world critical thinking.

Level 1
Foundation

Start with factoring and the zero-product property.

ax² + bx + c = 0
  1. Move all terms to one side.
  2. Find two numbers with the required product and sum.
  3. Factor the quadratic.
  4. Set each factor equal to zero.
  5. Check both solutions.
Practice: x² − 5x + 6 = 0

Find two numbers whose product is 6 and whose sum is −5.

Think about the factor pair of 6 that has a negative sum.
Level 2
Standard

Use the quadratic formula when factoring is not convenient.

x = (−b ± √(b² − 4ac)) / 2a
Practice: 2x² − 7x + 3 = 0
  1. Identify a, b, and c.
  2. Calculate D = b² − 4ac.
  3. Substitute into the quadratic formula.
  4. Simplify both ± cases.
Start with a = 2, b = −7, c = 3. Calculate the discriminant before doing anything else.
Level 3
Advanced

Apply quadratic equations to a realistic situation and interpret the result.

Garden challenge

A rectangular garden has an area of 96 m². Its length is 4 m greater than its width. Determine its dimensions.

  1. Let the width be x.
  2. Express the length as x + 4.
  3. Build an equation from the area.
  4. Solve it and reject any non-physical solution.
Critical thinking

How can the discriminant tell you whether a real-world quadratic model has zero, one, or two real solutions?
